# 🎯 Jogo de Tiro ao Alvo

Um jogo simples e interativo de tiro ao alvo desenvolvido com **HTML5, CSS3 e JavaScript puro (Vanilla JS)**. Clicando nas diferentes camadas do alvo, você acumula pontos de acordo com a precisão do disparo!
